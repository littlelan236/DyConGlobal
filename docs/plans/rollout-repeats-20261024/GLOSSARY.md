# DyConGlobal 重复采样术语草案

这是改造计划的术语附件，补充工程现有 Task、Rollout、Run evidence 和 Trajectory selection 定义。方案实施后再合并到工程根词汇表。

## 独立采样与执行

**Repetition（独立采样）**：同一任务的一次预先计划的独立智能体运行，具有独立环境和采样设置。无论是否解题成功，它都属于该实验的一个采样名额。
_Avoid_：把基础设施重试称作一次新的 repetition。

**Repeat count（采样总次数）**：一次实验为每个选中任务计划的独立采样数量，包含第一次运行。失败后的基础设施重试不增加此数。
_Avoid_：额外追加次数、成功轨迹配额。

**Sample slot（样本槽位）**：实验为某个任务的某次独立采样预留的名额。它可能取得一条真实终态轨迹，也可能在基础设施失败后耗尽而没有有效结果。
_Avoid_：成功样本、resolved rollout。

**Execution attempt（执行尝试）**：为取得一个样本槽位的结果而进行的一次实际执行。基础设施故障后的重新执行仍属于原槽位，原尝试的证据保留。
_Avoid_：独立重复采样；也不要与现有 Training attempt 混用。

**Final sample trajectory（样本最终轨迹）**：某个样本槽位最终绑定、用于默认评分和分析的那条真实轨迹。为基础设施故障保留的早期执行轨迹不自动构成额外独立样本。
_Avoid_：按最新时间猜测的轨迹、同一 patch 的任意副本。

**Settled sample（已结算样本）**：已经取得明确终态或明确失败结果、无需继续自动执行的样本槽位。已结算不表示已提交、已通过评分或 hidden 已完整发布。
_Avoid_：resolved、上传完成。
